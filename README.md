# Resume Website — Starter

Files:
- index.html — main single-page resume
- styles.css — styles (responsive + print)
- script.js — theme toggle + smooth scroll
- resume.pdf — optional downloadable PDF (replace with your PDF file)

How to use:
1. Replace the placeholder text (YOUR NAME, summaries, jobs, links).
2. Optionally replace resume.pdf with a printable export of your resume.
3. Open `index.html` in your browser to preview.

Printing to PDF:
- Open the page in Chrome/Edge and use Print → Save as PDF. The page includes a print stylesheet to produce a clean PDF.

Deploy:
- Quick: Push to a GitHub repo and enable GitHub Pages (deploy from main branch / root).
- Or deploy on Netlify / Vercel by pointing at the repo.

Customization tips:
- Change colors in :root variables inside `styles.css`.
- Add icons (SVG inline) or social links where appropriate.
- Replace the simple contact form with a real form service (Formspree, Netlify Forms) or a mailto link.

Accessibility:
- Use semantic headings and alt text if you add images.
- Keep contrast high and test keyboard navigation.
